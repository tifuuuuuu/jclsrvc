Configuration

Environment variables passed to your app at runtime. PORT is injected automatically. Changes apply on the next start / restart.

Bulk import from .env or localSettings.json

Paste a .env file (KEY=value lines) or an Azure localSettings.json. Variables are added to the list above — review, then Save.

🔒 Values are encrypted at rest in apps.json.

Health check path

Optional HTTP path probed for liveness (any status < 500 is healthy). Blank = TCP connect only. Also gates the zero-downtime cutover on deploy.

Sharing

Collaborators (by Google email) can see and control this app. Owner only.

Access restrictions

Applied at the proxy, before a request reaches your app — so they cover the subdomain, custom domains, and WebSockets alike. Leave both blank to keep the app public. Takes effect immediately.

Password

Visitors get a browser sign-in prompt (HTTP Basic; any username). Stored encrypted, never shown again.

Allowed IPs

One per line — an exact address, or a prefix ending in a dot (192.168.1. = that whole subnet). Blank = any address.

Idle sleep

Stop the app after a stretch with no traffic and start it again on the next request, so idle apps stop holding memory. The first request after sleeping waits for the app to boot. 0 = always on.

minutes idle

Scheduled jobs

Commands run on a cron schedule in your app's folder, with its environment variables (Docker apps: inside the container). Output goes to the log stream. A job still running when it comes due again is skipped.

Five fields — minute hour day month weekday. 0 3 * * * = 3am daily · */15 * * * * = every 15 min · 0 9 * * 1 = Mondays 9am (Sunday = 0).

API token

Bearer token for the API (CLI / CI). Send Authorization: Bearer <token>. Generating a new one revokes the old.

Scale up (plan)

Each plan sets a real memory ceiling. An app that overruns its plan is restarted; Node also gets a matching heap cap (--max-old-space-size), Docker apps a --memory limit. Applies on next start / restart.

Current plan: Free · memory cap 512 MB

Custom domains

Every running app gets a .localhost subdomain. To use your own hostname, point its DNS at this server, then add it here — the reverse proxy routes it. For HTTPS, set SSL_CERT / SSL_KEY on the server.
